Cyber Security

Cyber Security atau keamanan siber adalah bidang teknologi informasi yang berfokus pada perlindungan sistem komputer, jaringan, aplikasi, dan data dari berbagai ancaman digital, seperti peretasan, pencurian data, virus komputer, dan akses tanpa izin. Cyber security bertujuan untuk menjaga kerahasiaan, keutuhan, dan ketersediaan informasi agar tetap aman dari pihak yang tidak bertanggung jawab. Penerapan cyber security dapat dilakukan melalui penggunaan kata sandi yang kuat, autentikasi dua faktor, antivirus, firewall, serta enkripsi data. Contoh penerapannya adalah melindungi akun media sosial dari peretasan, mengamankan data pengguna pada website, dan menjaga keamanan sistem perbankan digital

Web Development

Web Development adalah proses merancang, membuat, mengembangkan, menguji, dan memelihara website atau aplikasi berbasis web agar dapat berfungsi sesuai kebutuhan pengguna. Web development mencakup beberapa bagian, yaitu front-end development yang berfokus pada tampilan dan interaksi pengguna, back-end development yang mengelola proses di balik layar seperti server dan pengolahan data, serta full-stack development yang menggabungkan keduanya. Dalam proses pengembangannya, web developer menggunakan berbagai teknologi, seperti HTML untuk menyusun struktur halaman, CSS untuk mengatur tampilan, JavaScript untuk menambahkan interaksi, serta bahasa dan teknologi lainnya untuk mengelola server dan database. Contoh hasil web development adalah website sekolah, toko online, aplikasi perpustakaan digital, sistem absensi, dan website portofolio.

Web Developer

Web Developer adalah seseorang yang memiliki keterampilan dalam membuat, mengembangkan, menguji, dan memelihara website atau aplikasi berbasis web menggunakan berbagai bahasa pemrograman dan teknologi web. Seorang web developer bertanggung jawab memastikan website memiliki tampilan yang baik, berfungsi dengan benar, mudah digunakan, aman, dan dapat diakses melalui berbagai perangkat, seperti komputer, laptop, dan smartphone. Web developer memiliki beberapa jenis, yaitu front-end developer yang mengembangkan tampilan website, back-end developer yang menangani server, database, dan logika aplikasi, serta full-stack developer yang menguasai pengembangan front-end dan back-end. Untuk menjadi web developer, seseorang perlu mempelajari HTML, CSS, JavaScript, pengelolaan database, serta penggunaan alat pengembangan seperti Visual Studio Code dan Git. Contoh pekerjaan web developer adalah membuat website perusahaan, mengembangkan aplikasi pembelajaran online, membangun sistem pemesanan, dan membuat website portofolio pribadi.
